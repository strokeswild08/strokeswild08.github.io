# Capture the Unreal prototype after validation

No Unreal gameplay footage is shipped with this source project. After the editor acceptance checks pass, record a short capture using this sequence:

| Time | Show |
| --- | --- |
| 0–5 s | Range title/HUD, mouse look and the five targets |
| 5–13 s | Hit three targets and show the hits/shots counters |
| 13–20 s | Fire a few rounds, start reload, attempt fire, then show reserve transfer |
| 20–28 s | Press J, attempt fire/reload, press F, fire after clear completes |
| 28–35 s | Hold right mouse for focus, fire, then reset the range |

Use a Development build if you want the debug tracer visible. Describe the gun as procedural blockout geometry, and label footage with the engine version and commit tested. Do not present a browser bench recording as Unreal footage.
