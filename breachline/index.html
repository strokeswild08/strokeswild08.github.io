UNDER THE RECEIVER

Small system.
Deliberate rules.

One state machine owns the ammunition and action timing. The engine handles input, traces and feedback around it.

01 / STATE

Actions cannot overlap.

Reloading blocks fire. A jam blocks reloading. Clearing takes one second and returns the weapon to ready.

02 / ACCOUNTING

No free ammunition.

Reloads transfer existing reserve rounds. Stoppages do not spend a round. Empty magazines stay empty until reloaded.

03 / SOURCE

Unreal C++ included.

A reusable actor component, first-person character and procedural range. This browser bench is a separate 2D companion, not an Unreal export.
